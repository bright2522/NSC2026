3) bright/RecipeSelectionManager
   - recipes[] (RecipeData) — ข้อมูล UI
   → PEP ต้อง sync กับ RecipeSO ชุดเดียว

4) coco/CookingGameManager (namespace CookingGame)
   - SelectRecipe(int index) — ใช้ RecipeDatabase
   - OnStepCompleted(float score) / totalRecipeScore / GetRecipeMedal()
   - Minigame controllers: chopping, stirring, grilling, seasoning, pounding
   → PEP ScoringManager ฟัง event จากที่นี่

5) coco/RecipeDatabase + Recipe + RecipeStep
   - 10 สูตรไทย + step → minigame type

   - OnStateChanged, ShowFinalRecipeResult, ShowStepResult
   → PEP NutritionDisplay ต่อท้าย recipeComplete state

7) folk/SliceableFood + KnifeMovement (ถ้าใช้)
   - tag "Knife" / "Sliceable"
   - ไม่มี callback score — PEP ต้องเขียน adapter เอง

เนื้อเรื่องย่อ
================================================================================
สรุปเนื้อเรื่องเกม (Story / Core Concept)
เกม: Smart Food Smart Life
แนว: 3D Cooking Simulation + Gamification + Healthy Eating Education
เนื้อเรื่องย่อ
ผู้เล่นเป็นคนที่ต้องการเรียนรู้การทำอาหารเพื่อสุขภาพที่ดีขึ้น
→ เลือก ช่วงอายุ (เด็ก/วัยรุ่น, วัยทำงาน, ผู้สูงอายุ)
→ เลือกโหมด เรียนรู้ผ่านเกม หรือ ทำในชีวิตจริง
→ ใช้ Smart Fridge เลือกวัตถุดิบที่มี → ระบบแนะนำเมนูที่เหมาะสม
→ เข้า Mini-game จำลองการทำอาหารจริง (หั่น, ควบคุมไฟ, ต้ม/ผัด/ย่าง)
→ ได้อาหารเสร็จ → ตรวจ Nutrition Score + Review
→ แชร์ใน Community หรือไป แข่ง 1v1 กับเพื่อน
Pain Point ที่เกมแก้ (สำคัญสำหรับ GameStateMachine)

คนรุ่นใหม่ขาดความรู้โภชนาการ → กิน junk food → โรคอ้วน เบาหวาน ความดันสูง
มองว่าทำอาหารยาก น่าเบื่อ
อยากกินอร่อยแต่ไม่รู้ว่าจะทำยังไงให้ทั้งอร่อยและดีต่อสุขภาพ

เกมจึงเปลี่ยนการเรียนรู้โภชนาการให้เป็นเกมสนุก ที่ผู้เล่นได้ฝึกจริง + นำไปใช้ในชีวิตจริงได้

สำหรับ GameStateMachine แนะนำ Flow หลัก:

MainMenu
Age Selection
Mode Selection (Game Mode / Real Life)
Solo → Smart Fridge → Recipe Select → Cooking Sequence (State Machine)
Result / Nutrition Review
Community / Reward / Shop
Competition Lobby → Battle

Core Loop: Fridge → Cook (Mini-games) → Score → Reward
ต้องการให้แยก State เพิ่มเติมไหม?
